Veille du 2026-09-25

Semaine du 18 au 25 septembre 2026. Synthèse des faits marquants, priorité aux sources primaires (éditeurs, CERT-FR/CISA, avis de sécurité). Les quelques éléments légèrement antérieurs à la fenêtre de 7 jours sont datés explicitement.

Administration systèmes et infrastructures IT

  • Windows Server : Microsoft acte la dépréciation de WDS (24 sept. 2026) — Le rôle Windows Deployment Services (service WDS, outils de gestion et amorçage PXE) sera déprécié dès la prochaine version de Windows Server. Il faut planifier la migration du déploiement d'images vers une alternative comme Microsoft Configuration Manager. Impact direct sur les chaînes de provisioning OS. Microsoft – Windows message center

  • Windows 11 24H2 : dernière preview et fin de support qui approche (note mise à jour le 22 sept. 2026) — La mise à jour d'aperçu non-sécurité de septembre (KB5124010) est la dernière preview pour Windows 11 24H2. Les éditions Home et Pro de la 24H2 atteignent la fin de support en octobre 2026 ; seuls les correctifs de sécurité mensuels continueront. À anticiper pour les parcs encore en 24H2. Microsoft – Windows message center

  • ESU disponibles pour Windows Server 2016 et Windows 10 LTSC 2021 (septembre 2026) — Les Extended Security Updates sont désormais achetables (tarif unifié quel que soit le canal ou l'emplacement, gestion possible via Azure Arc) avant la fin de support du 12 janvier 2027. À budgéter dès maintenant pour les serveurs et postes qui ne seront pas migrés à temps. Long View – September 2026 Microsoft Licensing News · Microsoft Partner Center – annonces sept. 2026

Cybersécurité

  • CISA ajoute 4 failles activement exploitées au catalogue KEV (22 sept. 2026) — Échéance de correction fédérale au 25 sept. Concernés : F5 BIG-IP (CVE-2026-94127, RCE), Arista VeloCloud Orchestrator (CVE-2026-93952, CVSS 10.0, accès privilégié non authentifié) et Check Point (CVE-2026-93616 et CVE-2026-85102). Le CERT-FR a relayé F5 et Check Point comme « activement exploitées » dès le 23 sept. À patcher en priorité sur tout équipement exposé. CISA – KEV 22/09 · CERT-FR AVI-1220 (F5) · CERT-FR AVI-1219 (Check Point)

  • Rançongiciels : nouveau record 2026 en août (rapport publié le 23 sept. 2026) — Selon la CTI d'août de NCC Group, 1 073 organisations victimes de rançongiciel dans le mois (+12 % vs juillet, plus haut niveau de l'année). Groupes dominants : Qilin (164 attributions) et The Gentlemen (116) ; secteur industriel le plus visé (31 %). Confirme la tendance à l'extorsion/vol de données sans chiffrement. Infosecurity Magazine / NCC Group

  • Avis conjoint international contre le mode opératoire nord-coréen « WaterPlum » / Contagious Interview (avis du 18 sept. 2026) — FBI, NPA japonaise, ACSC australienne et services allemands documentent une campagne ayant infecté 30 000 appareils dans 100+ pays et compromis 7 000+ portefeuilles crypto (~10,7 M$ détournés). Vecteur : faux entretiens d'embauche poussant des paquets NPM/projets VS Code malveillants (BeaverTail, OtterCookie…). Rappel : ouvrir tout projet inconnu en mode restreint. Infosecurity Magazine · Avis IC3 (PDF)

  • Salve d'avis CERT-FR à corriger (23–24 sept. 2026) — Correctifs notables pour Microsoft Office (RCE, AVI-1224), GitLab (exécution de code, AVI-1225), PHP (AVI-1227), ainsi que PaperCut, Wireshark et Apache Tomcat. À intégrer au cycle de patch en cours. CERT-FR – Avis de sécurité

Bases de données

  • PostgreSQL 19 Beta 4 disponible (24 sept. 2026) — Dernière beta avant la release candidate attendue début octobre (GA possiblement en octobre). Fait notable : plusieurs fonctionnalités initialement prévues pour la v19 ont été retirées au nom de la fiabilité — SQL/PGQ (requêtes de graphes), activation/désactivation en ligne des sommes de contrôle, mises à jour/suppressions temporelles FOR PORTION OF, MERGE/SPLIT PARTITIONS. À tester dès maintenant sur charges représentatives. PostgreSQL.org

  • Oracle Critical Security Patch Update – Septembre 2026 (Rev 1, 15 sept. 2026) — 13 correctifs pour les produits base de données Oracle (dont 11 pour Oracle Database Server) ; 5 vulnérabilités exploitables à distance sans authentification. Événement de sécurité trimestriel majeur côté DB à appliquer sur les environnements Oracle. Oracle Security Alerts

  • Rappel côté SQL Server — Le Patch Tuesday du 8 sept. 2026 (édition record, 900+ CVE) a corrigé plusieurs failles critiques de Microsoft SQL Server, dont CVE-2026-65669 (CVSS 9.6). À vérifier sur les instances non encore patchées. CrowdStrike – analyse Patch Tuesday sept. 2026

Pilotage de projet

  • Microsoft Project Online se retire le 30 septembre 2026 — Échéance imminente. Après cette date, l'accès au service et aux données disparaît : les PMO doivent exporter leurs données avant la bascule. Trajectoires de migration : Planner (licences Planner Plan 1 / Planner and Project Plan 3 ou 5), Project Server Subscription Edition, ou Dynamics 365 Project Operations. Project desktop et Project Server ne sont pas concernés. Microsoft mise sur Planner + l'agent IA « Project Manager » et Copilot. Microsoft – Planner Blog

  • Jira auto-hébergé (Data Center) : trajectoire de fin de vie (analyse du 23 sept. 2026) — Atlassian ne vend plus Jira Software Data Center aux nouveaux clients et consolide autour du cloud et de l'IA. Pour les clients existants : 30 mars 2028 = dernière date d'achats d'extension, 28 mars 2029 = Jira auto-géré passe en lecture seule. À intégrer aux feuilles de route outillage/PMO, en parallèle du dossier Project Online. WindowsForum – analyse marché PM

  • Fond de tableau : consolidation vers le cloud et l'IA — Ces deux mouvements (retrait de Project Online, borne EOL sur Jira DC) illustrent la bascule 2026 des outils de gestion de projet vers des plateformes cloud-first à assistance IA. Les PMO qui renouvellent ou choisissent un outil ce trimestre doivent vérifier les dates de fin de service avant de s'engager. WindowsForum
