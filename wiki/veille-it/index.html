Veille du 2026-10-05

Période couverte : 28 septembre au 5 octobre 2026. Priorité aux sources primaires (éditeurs, CERT-FR/ANSSI, CISA, avis CVE). Le complément Hacker News (top 50 des stories) a été passé en revue : aucun événement d'infrastructure, de cybersécurité ou de base de données à ajouter sur la fenêtre au-delà des sources citées ci-dessous.

1. Administration systèmes et infrastructures IT

Windows 11 version 26H2 : sauvegarde des paramètres activée par défaut (30 septembre 2026). Avec le déploiement de la mise à jour 2026 (26H2), Microsoft active par défaut la stratégie de sauvegarde des paramètres Windows sur les appareils éligibles, sauf réglage explicite contraire de l'administrateur. Pour les parcs, cela devient une base de résilience : un poste réinitialisé, remplacé ou mis à niveau retrouve plus facilement ses réglages et sa liste d'applications du Store. Pilotable via Intune, GPO ou MDM. Source : Microsoft, Windows message center.

VMware : Broadcom pousse vSphere Foundation 9.1, fin du support de vSphere 8 en octobre 2027 (28 septembre 2026). Un billet VMware chiffre l'intérêt économique de passer à VCF / vSphere Foundation 9.1, alors que le support général de vSphere 8 s'arrête en octobre 2027 et que les détails d'une nouvelle édition vSphere Standard sont attendus à VMware Explore (Francfort, mi-octobre). Les équipes sous VMware doivent arbitrer entre migration vers 9.1, renouvellement ou sortie. Sources : VMware Cloud Foundation blog, CRN.

Microsoft 365 : blocage des Exchange Web Services (EWS) pour les applications tierces (1er octobre 2026). Depuis le 1er octobre, Exchange Online bloque les requêtes EWS issues d'applications non-Microsoft ; Outlook, Teams et les autres produits Microsoft ne sont pas touchés. Les intégrations tierces encore sur EWS doivent basculer vers Microsoft Graph. Source : Microsoft, blog Exchange (retrait d'EWS).

Autres échéances Microsoft d'octobre à anticiper. Retrait de l'interface des stratégies de risque (connexion et utilisateur) dans Entra ID Protection, à migrer vers l'accès conditionnel (1er octobre) ; bascule de l'authentification de partage externe SharePoint et OneDrive du code à usage unique vers Entra B2B (octobre) ; retrait de Microsoft Publisher (13 octobre). Source : suivi AdminDroid des changements M365 (références Message Center).

2. Cybersécurité

Citrix NetScaler ADC et Gateway : huit failles, deux zero-days exploités en exécution de code (CERT-FR le 28 septembre, CISA mise à jour le 2 octobre 2026). Citrix corrige huit vulnérabilités (CVE-2026-88771 à CVE-2026-88778). La CISA ajoute CVE-2026-88771 et CVE-2026-88772 à son catalogue KEV : deux failles critiques d'exécution de code à distance activement exploitées à l'échelle mondiale. Rechercher les indicateurs de compromission avant d'appliquer les correctifs, car la mise à jour peut faire perdre des traces forensiques. Sources : CERT-FR ALE-011, CISA.

Cisco Catalyst SD-WAN Manager : contournement d'authentification critique exploité (CVE-2026-76504, CVSS 9.8) (avis Cisco du 30 septembre 2026). Une mauvaise gestion de l'encodage d'URI permet à un attaquant non authentifié d'obtenir un accès administrateur à l'API du Manager. Il s'agit du cinquième zero-day SD-WAN de Cisco en 2026 ; la faille a été ajoutée au KEV de la CISA le 30 septembre, avec remédiation fédérale exigée au 3 octobre. Sources : avis Cisco, BleepingComputer.

Fortinet FortiMail : zero-day critique exploité (CVE-2026-104286, CVSS 9.8) (CISA KEV le 1er octobre, CERT-FR le 2 octobre 2026). Un défaut de traversée de chemin permet à un attaquant non authentifié d'écrire des fichiers arbitraires et de lire des données sensibles via des requêtes HTTP forgées (FortiMail 8.0.0 à 8.0.1). Correctif à appliquer sans délai sur les passerelles de messagerie exposées. Sources : CISA KEV, CERT-FR AVI-1257, The Hacker News.

Apple corrige en urgence une faille CoreGraphics liée à des attaques ciblées (CVE-2026-86950) (28 septembre 2026). Un dépassement de mémoire dans le rendu 2D et PDF peut mener à l'exécution de code au traitement d'un fichier piégé ; Apple évoque une attaque « extrêmement sophistiquée » contre des individus visés (iOS antérieurs à la version 27), faille signalée par Meta. Correctifs : iOS et iPadOS 26.7.1, macOS Tahoe 26.7.1, macOS Sequoia 15.8.1. Prioriser les utilisateurs à risque et vérifier le déploiement via MDM. Source : SOC Prime (reprenant SecurityWeek et l'avis Apple).

CERT-FR : retour d'expérience sur les vulnérabilités des produits de santé (2 octobre 2026). Le CERT-FR et le CERT Santé publient un rapport (CTI-007) sur la gestion des vulnérabilités dans les produits du secteur de la santé, utile aux RSSI et équipes SOC concernés. Source : CERT-FR CTI-007.

3. Bases de données

MongoDB 9.0 disponible, avec Atlas Infinite et Atlas Agent Engine (29 septembre 2026). Version majeure annoncée à New York : jusqu'à 2 fois plus de débit sur les grosses instances, lectures environ 35 % plus rapides et mises à jour environ 30 % plus rapides que la 8.0, auxquelles s'ajoutent des briques orientées charges IA (Atlas Infinite, Atlas Agent Engine en préversion publique). Fin de vie annoncée au 31 octobre 2031. Sources : MongoDB (communiqué), MongoDB Updates.

MySQL : fin du support d'Oracle Solaris (effective le 29 septembre 2026). Selon l'avis officiel MySQL, Oracle ne fournit plus de nouvelles versions, binaires, correctifs de bugs ni correctifs de sécurité pour MySQL sur Oracle Solaris. Les déploiements MySQL sur cette plateforme doivent planifier une migration. La prochaine version Innovation (MySQL 26.10) est attendue sur la fenêtre d'octobre. Source : MySQL (annonces de fin de support).

PostgreSQL 19 : version finale attendue en octobre 2026 (à venir). La bêta 4 a été publiée le 24 septembre et la feuille de route vise une sortie finale en octobre 2026. À surveiller pour les tests de compatibilité et les plans de montée de version. Sources : PostgreSQL (roadmap), PostgreSQL (actualités).

Semaine par ailleurs calme côté SQL Server et Oracle Database : pas d'annonce majeure sur la fenêtre.

4. Pilotage de projet

Atlassian Team '26 Europe (Amsterdam, 6 au 8 octobre 2026) : les agents IA entrent dans Jira. L'événement phare ouvre cette semaine. Atlassian positionne Jira en moteur de coordination orchestrant travail humain et agents IA (Agents in Jira), avec Rovo et un Rovo MCP Server donnant à des agents tiers (Claude, Cursor, ChatGPT) l'accès aux tickets Jira et aux pages Confluence. Enjeu pour les PMO : gouvernance et sécurité des agents dans les workflows projet. Sources : Atlassian (événement), Adaptavist (annonces Team '26).

Hausse des tarifs Atlassian Cloud, effective en octobre 2026. Atlassian relève ses prix Cloud en intégrant les capacités IA (Rovo, agents) au cœur de l'offre. Impact direct sur les budgets d'outillage PMO, à anticiper lors des renouvellements. Source : Adaptavist.

Fin de vie d'Advanced Roadmaps for Jira et horizon de sortie du Data Center. Advanced Roadmaps for Jira est désormais en fin de vie ; en parallèle, Atlassian confirme l'arrêt de ses produits Jira Data Center à l'horizon mars 2029, sans option on-premise ensuite. Les organisations encore en Data Center doivent planifier leur trajectoire Cloud. Source : Atlassian (politique de fin de support).

Note : l'actualité « pilotage de projet » de la semaine est dominée par Atlassian Team '26.

Veille du 2026-09-25

Semaine du 18 au 25 septembre 2026. Synthèse des faits marquants, priorité aux sources primaires (éditeurs, CERT-FR/CISA, avis de sécurité). Les quelques éléments légèrement antérieurs à la fenêtre de 7 jours sont datés explicitement.

Administration systèmes et infrastructures IT

  • Windows Server : Microsoft acte la dépréciation de WDS (24 sept. 2026) — Le rôle Windows Deployment Services (service WDS, outils de gestion et amorçage PXE) sera déprécié dès la prochaine version de Windows Server. Il faut planifier la migration du déploiement d'images vers une alternative comme Microsoft Configuration Manager. Impact direct sur les chaînes de provisioning OS. Microsoft – Windows message center

  • Windows 11 24H2 : dernière preview et fin de support qui approche (note mise à jour le 22 sept. 2026) — La mise à jour d'aperçu non-sécurité de septembre (KB5124010) est la dernière preview pour Windows 11 24H2. Les éditions Home et Pro de la 24H2 atteignent la fin de support en octobre 2026 ; seuls les correctifs de sécurité mensuels continueront. À anticiper pour les parcs encore en 24H2. Microsoft – Windows message center

  • ESU disponibles pour Windows Server 2016 et Windows 10 LTSC 2021 (septembre 2026) — Les Extended Security Updates sont désormais achetables (tarif unifié quel que soit le canal ou l'emplacement, gestion possible via Azure Arc) avant la fin de support du 12 janvier 2027. À budgéter dès maintenant pour les serveurs et postes qui ne seront pas migrés à temps. Long View – September 2026 Microsoft Licensing News · Microsoft Partner Center – annonces sept. 2026

Cybersécurité

  • CISA ajoute 4 failles activement exploitées au catalogue KEV (22 sept. 2026) — Échéance de correction fédérale au 25 sept. Concernés : F5 BIG-IP (CVE-2026-94127, RCE), Arista VeloCloud Orchestrator (CVE-2026-93952, CVSS 10.0, accès privilégié non authentifié) et Check Point (CVE-2026-93616 et CVE-2026-85102). Le CERT-FR a relayé F5 et Check Point comme « activement exploitées » dès le 23 sept. À patcher en priorité sur tout équipement exposé. CISA – KEV 22/09 · CERT-FR AVI-1220 (F5) · CERT-FR AVI-1219 (Check Point)

  • Rançongiciels : nouveau record 2026 en août (rapport publié le 23 sept. 2026) — Selon la CTI d'août de NCC Group, 1 073 organisations victimes de rançongiciel dans le mois (+12 % vs juillet, plus haut niveau de l'année). Groupes dominants : Qilin (164 attributions) et The Gentlemen (116) ; secteur industriel le plus visé (31 %). Confirme la tendance à l'extorsion/vol de données sans chiffrement. Infosecurity Magazine / NCC Group

  • Avis conjoint international contre le mode opératoire nord-coréen « WaterPlum » / Contagious Interview (avis du 18 sept. 2026) — FBI, NPA japonaise, ACSC australienne et services allemands documentent une campagne ayant infecté 30 000 appareils dans 100+ pays et compromis 7 000+ portefeuilles crypto (~10,7 M$ détournés). Vecteur : faux entretiens d'embauche poussant des paquets NPM/projets VS Code malveillants (BeaverTail, OtterCookie…). Rappel : ouvrir tout projet inconnu en mode restreint. Infosecurity Magazine · Avis IC3 (PDF)

  • Salve d'avis CERT-FR à corriger (23–24 sept. 2026) — Correctifs notables pour Microsoft Office (RCE, AVI-1224), GitLab (exécution de code, AVI-1225), PHP (AVI-1227), ainsi que PaperCut, Wireshark et Apache Tomcat. À intégrer au cycle de patch en cours. CERT-FR – Avis de sécurité

Bases de données

  • PostgreSQL 19 Beta 4 disponible (24 sept. 2026) — Dernière beta avant la release candidate attendue début octobre (GA possiblement en octobre). Fait notable : plusieurs fonctionnalités initialement prévues pour la v19 ont été retirées au nom de la fiabilité — SQL/PGQ (requêtes de graphes), activation/désactivation en ligne des sommes de contrôle, mises à jour/suppressions temporelles FOR PORTION OF, MERGE/SPLIT PARTITIONS. À tester dès maintenant sur charges représentatives. PostgreSQL.org

  • Oracle Critical Security Patch Update – Septembre 2026 (Rev 1, 15 sept. 2026) — 13 correctifs pour les produits base de données Oracle (dont 11 pour Oracle Database Server) ; 5 vulnérabilités exploitables à distance sans authentification. Événement de sécurité trimestriel majeur côté DB à appliquer sur les environnements Oracle. Oracle Security Alerts

  • Rappel côté SQL Server — Le Patch Tuesday du 8 sept. 2026 (édition record, 900+ CVE) a corrigé plusieurs failles critiques de Microsoft SQL Server, dont CVE-2026-65669 (CVSS 9.6). À vérifier sur les instances non encore patchées. CrowdStrike – analyse Patch Tuesday sept. 2026

Pilotage de projet

  • Microsoft Project Online se retire le 30 septembre 2026 — Échéance imminente. Après cette date, l'accès au service et aux données disparaît : les PMO doivent exporter leurs données avant la bascule. Trajectoires de migration : Planner (licences Planner Plan 1 / Planner and Project Plan 3 ou 5), Project Server Subscription Edition, ou Dynamics 365 Project Operations. Project desktop et Project Server ne sont pas concernés. Microsoft mise sur Planner + l'agent IA « Project Manager » et Copilot. Microsoft – Planner Blog

  • Jira auto-hébergé (Data Center) : trajectoire de fin de vie (analyse du 23 sept. 2026) — Atlassian ne vend plus Jira Software Data Center aux nouveaux clients et consolide autour du cloud et de l'IA. Pour les clients existants : 30 mars 2028 = dernière date d'achats d'extension, 28 mars 2029 = Jira auto-géré passe en lecture seule. À intégrer aux feuilles de route outillage/PMO, en parallèle du dossier Project Online. WindowsForum – analyse marché PM

  • Fond de tableau : consolidation vers le cloud et l'IA — Ces deux mouvements (retrait de Project Online, borne EOL sur Jira DC) illustrent la bascule 2026 des outils de gestion de projet vers des plateformes cloud-first à assistance IA. Les PMO qui renouvellent ou choisissent un outil ce trimestre doivent vérifier les dates de fin de service avant de s'engager. WindowsForum
